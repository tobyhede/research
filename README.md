# research

Distillations and deep reads of books. Structure and workflow are defined in [AGENTS.md](AGENTS.md).

Books waiting to be read are tracked in [queue.md](queue.md). Drop the files in `inbox/` and run `python3 -I scripts/intake.py scan`.

Only the briefs and notes are committed. The book files, the extracted text, and the HTML readers hold the full text of each book, so they stay on your machine and Git ignores them. Markdown citations point to `source/source.txt`, which resolves once you have placed the book and run the extraction locally.
